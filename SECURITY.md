# Security Policy

Please do not include credentials, private datasets, personal information, or confidential model artifacts in public bug reports.

If you discover a secret or personal-data leak in the repository, remove public access to the affected material as soon as practical, rotate any exposed credential, and rewrite repository history if necessary before restoring access.

For ordinary software vulnerabilities, use the repository host's private security-reporting feature when available rather than opening a public issue with exploit details.
