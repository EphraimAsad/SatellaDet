# Contributing

Contributions are welcome.

1. Create a branch from the current development branch.
2. Keep changes focused and add tests when behaviour changes.
3. Run the test suite.
4. Run `python tools/privacy_scan.py .` before opening a pull request.
5. Do not submit datasets, private model weights, credentials, personal information, or confidential paths.

By contributing, you agree that your contribution may be distributed under the repository's Apache-2.0 license.
